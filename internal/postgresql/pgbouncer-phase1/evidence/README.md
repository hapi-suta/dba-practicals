# Evidence privacy and interpretation

These are actual rehearsal outputs. Trailing display whitespace is trimmed. Private machine addresses and local harness
paths have been replaced with role labels such as `[APP_PRIVATE_IP]`. Labels keep
route comparisons readable and are not executable addresses. Original outputs,
private inventory, keys and credentials remain outside the public repository.

Earlier failures are intentionally retained. See ../VALIDATION.md for the correction
and passing rerun; a historical failure is not a current passing assertion.
